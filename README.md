# Assistente Legislativo Público

Ferramenta aberta para apoio à elaboração de minutas legislativas,
voltada a câmaras municipais e outros órgãos legislativos.

## Características
- Sem cadastro
- Sem armazenamento de dados
- Uso livre
- Apoio à redação legislativa

## Como executar

```bash
pip install -r requirements.txt
streamlit run app.py
